# UX 리서치 — 페르소나 김서연 (29세, 스타트업 마케터, 영어 A2)

- 테스트 대상: http://localhost:3000 (BRIEFLY)
- 방법: Playwright Chromium, 모바일 뷰포트 390×844, 터치 시뮬레이션, storageState로 세션 간 로그인/설정 유지
- 스크린샷: `docs/reports/persona-raw/p1-shots/` (세션별 파일명 s1~s5 접두사)
- 테스트일: 2026-08-10

## 세션 1 — 첫 만남: 온보딩 + 첫 기사

**한 일**: 처음 방문 → 홈에서 바로 기사 목록 확인 → 첫 기사("A US Lawmaker Says He Was Held in the West Bank") 클릭 → 끝까지 스크롤.

**걸린 시간 체감**: 로딩 즉시, 기사 하나 읽는 데 1~2분. 부담 없음.

**😊 만족 순간**
- 회원가입/로그인 절차가 아예 없어서 진입 장벽이 0에 가까움 (설정 페이지에 "로그인은 준비 중이에요" 안내로 게스트 모드임을 명확히 알림).
- 문장이 짧고 쉬움(A2 난이도 체감 적절), 문장 안에 어려운 단어("settlers" → "정착민")가 바로 병기되어 있어 멈추지 않고 읽힘.
- 기사 하단에 "5개 매체에서 교차 확인" + 실제 출처 링크가 있어 신뢰감.

**😤 마찰 순간**
- [심각도 하] 온보딩이나 "레벨 진단" 절차 자체가 없음. 요청 시나리오가 기대한 진단 퀴즈는 존재하지 않고, 설정에서 A2/B1/B2를 그냥 셀프 선택하는 방식. 편하긴 하나 "내가 진짜 A2가 맞나?" 확신을 주는 장치는 없음.
- [심각도 중] 첫 화면 제목이 "2026년 7월 13일 월 · 지난 브리핑이에요"로 뜸. 테스트 시점(8월)과 한 달 가까이 차이 나는 날짜에 "지난 브리핑" 라벨까지 붙어 있어 "오늘 뉴스가 아닌가?" 하는 혼란을 줌. (데이터 최신성 이슈로 보이며, 실 서비스에서 최신일자가 채워지면 해소될 가능성 있음)

**🗯️ 속마음**: "어 회원가입 안 해도 되네, 편하다. ...근데 이거 왜 7월 뉴스지? 오늘 게 아닌가?"

## 세션 2 — 평일 아침: 15분 안에 브리핑 완주

**한 일**: 홈으로 복귀(첫 기사에 "✓ 읽음" 표시 확인) → 두 번째 기사부터 "다음 기사 →" 링크로 나머지 9개 연속 완독 → 완주 화면 도달.

**걸린 시간 체감**: 기사당 2분 표기, 다음 기사 이동이 끊김 없이 빨라서 10개를 15분 안에 다 볼 수 있겠다는 확신이 듦.

**😊 만족 순간**
- 진행률 "0/10 → 10/10" 카운터가 문장을 읽을 때마다(스크롤 시) 실시간으로 올라가 "얼마나 남았나"가 명확함.
- 완주 시 "☕✅ 오늘의 브리핑 끝!" 화면과 함께 읽은 기사 수, 연속 일수("🔥 1일 연속") 등 주간 브리핑 요약 카드가 떠서 성취감 있음.

**😤 마찰 순간**
- [심각도 하] 완주 후 홈으로 돌아오면 축하 배너 없이 조용히 "✓ 읽음" 체크만 남음. 완주했다는 뿌듯함이 오래 안 감.

**🗯️ 속마음**: "오, 다음기사 누르니까 술술 넘어가네. 이 정도면 지하철에서 충분히 다 보겠다."

## 세션 3 — 단어 중심: 클릭·저장, 사전 없는 단어, My 단어장

**한 일**: 밑줄 쳐진 단어("congressman") 탭 → 발음기호·뜻·예문·저장 버튼이 있는 사전 팝업 확인 → 저장 → My 페이지에서 단어장(1) 반영 확인. 이어서 밑줄 없는 일반 단어("visited") 탭 시도. My 페이지의 스크랩/단어장/문장 탭 구조 확인.

**걸린 시간 체감**: 사전 팝업이 즉각적으로 뜸.

**😊 만족 순간**
- 사전 팝업에 실제 읽던 문장이 예문으로 그대로 나와서 문맥이 바로 이해됨.
- 저장하면 My 페이지 카운트("단어 1", "문장 1")에 바로 반영되어 기록되는 느낌이 확실함.

**😤 마찰 순간**
- [심각도 중] 기사마다 사전이 연결된 단어는 딱 5개뿐(밑줄 표시). 그 외 단어("visited" 등)를 탭하면 사전 팝업이 뜨지 않고 대신 문장 전체가 하이라이트되며 "문장 저장" 시트가 뜨거나 아무 반응이 없음. "이 단어는 왜 뜻이 안 나오지?"라는 혼란 유발 — 정작 서연이 실제로 모르는 단어는 그 5개 안에 없을 확률이 높음.
- My 페이지의 "단어장" 빈 상태 안내문은 "기사에서 단어를 눌러 단어장에 저장해보세요"라고 명확히 안내하는데, 실제로는 아무 단어나 눌러서는 안 되고 밑줄 쳐진 단어만 가능하다는 점이 안내에서 드러나지 않음.

**🗯️ 속마음**: "이 단어는 밑줄 있어서 뜻 나오는데 이건 눌러도 왜 안 나와? 나 이 단어 모르는데... 버그인가?"

## 세션 4 — 재방문: 아카이브, 완주 화면, 주간 브리핑

**한 일**: "← 지난 브리핑" / `/archive` 진입 시도.

**😊 만족 순간**: 없음 (이 세션은 마찰 위주).

**😤 마찰 순간**
- [심각도 상] 첫 `/archive` 접속 시 브랜딩도 뒤로가기 버튼도 없는 흰 화면에 "Internal Server Error" 텍스트만 뜸. 그대로면 이탈 1순위 상황. 재시도하니 정상 로드됨 — 재현은 못 시켰지만 실제로 관측된 사실임. **[관찰, 불확실성 명시]** 같은 시간대에 로컬 서버가 약 100초간 응답하지 않는 현상도 별도로 관측되었는데, 이 세션과 동시에 다른 에이전트가 배포 작업을 하고 있었을 가능성이 있어(다른 에이전트 이름에 "PA-deploy-prep" 존재) 이 자체를 상시적 앱 결함이라 단정하긴 어려움. 다만 사용자가 이 화면을 마주치면 원인과 무관하게 즉시 이탈 트리거가 됨.
- [심각도 중] 재시도로 정상 로드된 아카이브에는 지난 브리핑 날짜가 "2026년 7월 13일" 딱 하루치뿐. "지난 기사 찾아보기"라는 기능 자체의 체감 가치가 현재는 거의 없음(테스트 데이터 부족 이슈로 보임).
- 완주 화면과 주간 브리핑 요약은 세션2에서 확인한 인라인 카드가 전부이고, 별도의 "완주 전용 화면"이나 "주간 브리핑 전용 페이지"는 발견하지 못함.

**🗯️ 속마음**: "어... 이거 그냥 흰 화면에 에러 뜨는데? 뭐야, 고장났나?"

## 세션 5 — 험한 날: 다크모드, 글자 크기, 중간 이탈 복귀, 새로고침

**한 일**: 다크모드 토글 → 글자 크기 S/M/L/XL 전환(실측 15.75px→18px→20.25px→22.5px, 정상 작동 확인) → 기사 중간(스크롤 900px)까지 읽다 홈으로 이탈 후 같은 기사 재진입 → 새로고침으로 다크모드/글자크기/진행률 유지 여부 확인.

**😊 만족 순간**
- 다크모드 전환이 즉시 반영되고 가독성 좋음, 배경색이 순검정이 아니라 눈이 편함.
- 글자 크기 조절 폭이 확실히 커서(S→XL 약 1.4배) 시력 안 좋은 날에도 유용.
- 새로고침해도 다크모드·글자크기·읽기 진행률(X/10)이 모두 그대로 유지됨 — 데이터가 안 날아간다는 안심.

**😤 마찰 순간**
- [심각도 중] 기사 읽다 중간에 나갔다가 같은 기사로 돌아오면 스크롤 위치가 맨 위로 초기화됨. "어디까지 읽었지?" 다시 훑어야 함. 지금은 기사가 10문장 남짓으로 짧아 타격이 작지만, 출근길처럼 자주 끊기는 상황이 반복되면 거슬릴 소지 있음.

**🗯️ 속마음**: "다크모드 예쁘다! ...근데 아까 어디까지 읽었더라, 처음부터 다시 봐야 하네."

## 종합 판정: 7일 후에도 쓸까?

**조건부 생존 (Yes, but fragile).** 핵심 루프인 "출근길 15분 안에 짧은 기사 10개 완독 + 단어 저장"은 실제로 매끄럽고 빠르며, 스트릭·진행률 같은 게임화 요소가 습관형성에 도움이 될 만큼 잘 작동한다. 회원가입 장벽이 없는 것도 이탈 없이 첫 세션을 넘기게 해주는 요인이다.

다만 서연은 "3번 막히면 삭제"하는 타입이다. 이번 세션에서만도 (1) 아카이브 접속 시 브랜딩 없는 Internal Server Error 화면, (2) 밑줄 없는 단어를 탭했을 때의 비일관적/무반응, (3) 첫인상부터 "오늘 뉴스가 아닌 것 같은" 날짜 혼란까지 짧은 시간에 여러 번 헷갈리거나 막히는 지점을 만났다. 매일 쓰는 핵심 화면(오늘의 브리핑)만 보면 살아남겠지만, 아카이브를 한 번이라도 누르거나 사전에 없는 단어를 몇 번 탭해보는 순간 "이거 왜 이래" 하고 삭제할 위험이 실재한다.

## 최우선 개선 3가지

1. **아카이브(`/archive`) 에러 화면 정비** — 브랜딩 없는 날것의 "Internal Server Error"는 최상급 이탈 트리거. 최소한 에러 바운더리 + 뒤로가기라도 필요.
2. **사전 없는 단어를 탭했을 때의 반응 정리** — 밑줄 없는 단어를 눌렀을 때 사전 팝업 대신 문장저장 시트가 뜨거나 무반응인 현재 흐름은 "이 단어 뜻은 없어요" 같은 명확한 피드백으로 바꿔야 함. 학습 앱의 핵심 기능(모르는 단어 찾기)이 걸려 있는 지점.
3. **콘텐츠 최신성(날짜) 확보** — 첫 화면부터 "지난 브리핑" + 낯선 날짜가 뜨는 것은 서비스 신뢰의 첫인상을 깎는다. 오늘 자 브리핑이 항상 채워지도록 하거나, 최소한 왜 지난 브리핑이 뜨는지 설명이 필요.

(부차: 기사 중도 이탈 후 재진입 시 스크롤 위치 미저장도 함께 손보면 좋음.)
