## 세션 1 — 수준 테스트: 최고 레벨 선택 → B2 정독 → 원문 비교

**한 일**
- 첫 진입 시 별도의 "온보딩 마법사" 화면 없이 바로 홈(A2 기본값)으로 떨어짐. `localStorage`에 `onboarded:false` 플래그가 있는 걸로 봐서 온보딩 로직 자체는 있는 듯한데, 화면상으로는 안 보임.
- Settings(⚙️)에서 레벨을 B2로 변경 → 홈의 모든 기사가 A2(2 min)에서 B2(4 min)로 즉시 갱신됨.
- McConnell 기사(B2)를 정독. 문장마다 단어 클릭 시 발음기호(IPA)+한글 뜻+문맥 예문 툴팁이 뜨고, "단어장에 저장" 버튼 있음.
- 기사 하단 "🔗 Sources" 3개 링크(Al Jazeera / BBC / The Guardian) 중 Al Jazeera 원문을 새 탭으로 실제 열어봄 → 정상 이동, 실제 기사 맞음.
- 원문과 B2 버전을 문장 단위로 대조: 원문엔 있고 B2엔 없는 것 — McConnell 직접 인용문("briefly unconscious", "I didn't have a heart attack or a stroke" 등), 상원 의석수 구체 수치(공화 51 vs 민주 47), 켄터키 주지사 Beshear의 공개서한 요청 사실, McConnell의 과거 낙상 이력(2023년 뇌진탕, 손목 부상), 퇴임 시점("1월 말 퇴임") 등 다수 누락.

**😊 만족**
- 단어 클릭 → IPA+뜻+문맥 예문 팝업은 체감 품질이 높음. "단어장에 저장" 버튼까지 바로 붙어있어 동선이 짧음.
- Sources 링크가 실제로 살아있고 새 탭(target=_blank)으로 열려서 원문 검증이 즉시 가능함.

**😤 마찰**
- (중) 온보딩 흐름 부재 — 처음 온 사용자가 "레벨을 골라야 한다"는 신호를 화면에서 못 받음. Settings를 스스로 찾아가야 레벨 변경 가능. `onboarded:false`인데 온보딩 UI가 없다는 건 설계와 구현 사이 괴리로 보임.
- (중) B2가 원문 대비 정보량이 상당히 얕음 — 인용문·수치·정치적 맥락(상원 의석 균형)이 다 빠져서, "이 정도면 원문 안 읽어도 되겠다" 싶다가도 실제 대조해보면 원문에만 있는 알맹이가 많음. 시사 영어 표현 사냥엔 오히려 원문이 나을 수도 있겠다는 인상.

**🗯️ 하늘의 속마음**
"B2 표시는 있는데 온보딩에서 물어봐준 적이 없네? 나 혼자 설정 찾아 들어간 거잖아. 그리고 이거 다 읽고 원문 열어보니까... 어, 숫자랑 인용문이 진짜 많이 빠졌네. 요약치고는 괜찮은데 '기사'라기보단 '리라이트'에 가깝구나."

## 세션 2 — 표현 수집: 단어·문장 저장 → 나중에 꺼내 쓰기

**한 일**
- McConnell 기사에서 단어(`hospitalization`) 1개 저장.
- 문장 하나("He offered an unusually personal explanation for why he had stayed quiet for so long.")를 클릭 → "문장 저장" 툴팁 → 저장.
  - 주의: 단어 뜻풀이 팝업이 열려 있는 상태에서는 그 팝업이 문장 클릭을 가로채서(overlay) 클릭이 타임아웃남. 팝업을 먼저 닫아야 다음 동작이 됨.
- 상단 "My"(실제 경로는 `/saved`, 네비게이션엔 "My"라고만 쓰여 있어 URL을 안다고 가정하면 안 됨) 페이지 진입 → 읽은 기사 1 · 스크랩 0 · 단어 1 · 문장 1 카운터 확인.
- "단어장 (1)" 탭 → 저장한 단어와 뜻, 삭제 버튼만 존재.
- "문장 (1)" 탭 → 저장한 문장 원문, 소속 기사 링크, 삭제 버튼만 존재.

**😊 만족**
- 문장 단위 저장이 실제로 됨 — 단어장만 있는 앱이 아니라 "인터뷰에 쓸 표현 통째로" 저장하는 용도로 쓸 수 있음.
- 저장한 문장에서 원본 기사로 되돌아가는 링크가 붙어있어 맥락을 다시 찾기 쉬움.

**😤 마찰**
- (상) 내보내기/복사 기능이 전혀 없음. 단어장·문장함 모두 "삭제" 버튼뿐, 복사 버튼도 텍스트 선택 안내도 없음. 면접 준비하면서 정리 노트(노션이나 워드)로 옮기려면 결국 화면 보고 손으로 타이핑해야 함.
- (중) 팝업이 다른 인터랙션을 막는 문제(위 기록) — 파워유저 입장에선 "왜 안 눌리지" 하고 한 번은 헷갈릴 지점.

**🗯️ 하늘의 속마음**
"오, 문장까지 저장되네, 좋다. 근데... 이거 다 모아놓고 나중에 어떻게 꺼내? 복사 버튼도 없고 내보내기도 없어. 결국 내가 일일이 타이핑해서 노션에 옮겨야 되는 거야? 표현 사냥은 잘 되는데 그다음이 없어."

## 세션 3 — 몰아서 완주: 10개 전부 + 완주 화면

**한 일**
- 홈에서 "다음 기사 →" 링크를 타고 4번째 기사(South Korea's Early-July Exports)까지 연속 읽기 진행하던 중, **http://localhost:3000 서버가 응답 없음(connection refused)** 상태가 됨. 프로세스 자체가 사라짐(`lsof -i :3000` 결과 없음). 지시대로 직접 재시작하지 않고 대기·확인만 반복함. 약 1분 뒤 다른 세션(운영자)이 "dev 서버 캐시 손상, 재기동 완료"로 복구시켜 이어서 진행함. `localStorage`는 그대로 보존되어 있어 저장했던 단어·문장·읽은 기사 기록은 끊기지 않았음.
- 복구 후 나머지 6개 기사를 "다음 기사 →" 순서대로 끝까지 읽음. 문단이 짧은 문장 단위로 끊겨 있어서 스크롤 속도감이 좋고, 카테고리(World/Korea/AI/Culture)가 섞여 있어도 흐름이 지루하지 않았음.
- 10번째 기사(Iran/Hormuz) 끝에서 완주 화면을 확인: "☕✅ 오늘의 브리핑 끝! 오늘 10개 기사를 모두 읽었어요 · 단어 1개, 문장 1개를 새로 담았어요" + 주간 브리핑 요약(읽은 기사 10 · 새 단어 1 · 저장 문장 1) + "🔥 1일 연속으로 브리핑을 읽고 있어요." 스트릭 표시 + "홈으로 →" 버튼.

**😊 만족**
- 완주 화면이 실제로 존재하고, 그날 활동(읽은 기사 수·새 단어·저장 문장)을 한 번에 정리해서 보여줌 — 몰아서 읽는 사용자에게 뿌듯함을 주는 마무리 장치로 잘 작동함.
- 연속 읽기 자체는(서버 사고 제외하면) 매끄러움. 문장이 짧고 리듬감 있어서 40분 몰아 읽기에 무리 없음.

**😤 마찰**
- (상) 완주 도중 서버가 죽어 순서가 끊김. 로컬 개발 서버 이슈라 실제 배포본과는 별개일 수 있지만, "저녁에 몰아서 쓴다"는 사용 패턴에서 이런 중단은 체감 타격이 큼.
- (하) "오늘의 브리핑" 자체는 지난 브리핑(7/13일자, "← 지난 브리핑"으로 표시)이라 오늘 날짜와 안 맞는 느낌 — 데모 데이터라서 그런 것으로 보이나, 실사용 시 "오늘"이란 표현과 실제 날짜가 어긋나면 신뢰가 흔들릴 수 있는 지점.

**🗯️ 하늘의 속마음**
"어 뭐야 갑자기 사이트가 안 열려... 다시 켜질 때까지 기다리는 수밖에 없네. 그래도 저장한 단어·문장은 안 날아갔다. 다행이다. 완주하니까 스트릭 뜨는 거 귀엽네, 이런 거 캡처해서 SNS에 올릴 만함."

## 세션 4 — 빈틈 찾기: 검색/퀴즈/발음재생 부재, 키보드 접근성

**한 일**
- 페이지 전체 HTML에서 "search/검색", "quiz/퀴즈", "audio/발음/🔊" 관련 키워드를 찾아봤으나, 실제 기능으로 이어지는 것은 하나도 없었음(전부 기사 본문 속 단어의 우연한 일치, 예: "...they **searched** for a way out").
- 단어 뜻 팝업에는 IPA 발음기호(예: `/ˌhɒspɪtəlaɪˈzeɪʃn/`)만 텍스트로 있고, 발음을 들어볼 수 있는 재생 버튼(🔊)이나 `<audio>` 요소는 DOM 어디에도 없음.
- 검색창·필터·퀴즈/복습 테스트 화면 자체가 없음. 지난 기사 목록도 "← 지난 브리핑"으로 하루 단위 이전/이후 이동만 가능하고, 키워드로 찾는 기능은 없음.
- 키보드 접근성 점검: Tab으로 로고 → 내비 → "지난 브리핑" → 기사 카드 순서로 포커스 이동, 포커스 링(2px solid)이 눈에 잘 보임. 기사 카드에서 Enter로 진입 성공. 기사 안에서 Tab으로 단어 버튼(`role="button" tabindex="0" aria-label="...뜻 보기"`)까지 도달, Enter로 뜻 팝업이 열리고 Escape로 닫힘 — 전부 마우스 없이 가능했음. 사전에 없는 단어("A" 같은 관사)를 열어도 "뜻 준비 중이에요. 저장해두면 사전이 업데이트될 때 알려드릴게요."라는 문구로 빈 결과를 매끄럽게 처리함.

**😊 만족**
- 예상외로 키보드만으로 카드 진입 → 단어 팝업 열기/저장 → 팝업 닫기까지 전부 가능했음. `aria-label`도 붙어있어 스크린리더 사용자 배려도 최소한은 되어있는 느낌.
- 사전 미등록 단어에 대한 처리(빈 결과 대신 안내 문구)가 매끄러워서 깨진 느낌이 없음.

**😤 마찰**
- (중) 검색 기능 없음 — "그때 그 기사 뭐였지" 하고 나중에 찾으려면 스크랩/저장 목록에만 의존해야 함. 지난 브리핑도 날짜를 하나씩 넘겨야 해서 특정 주제·키워드로 찾기는 불가능.
- (중) 퀴즈/복습 테스트 없음 — 단어장에 저장은 되지만 "내가 이 단어를 진짜 외웠는지" 확인할 방법이 없음. 저장하고 끝, 복습 루프가 없는 구조.
- (중) 발음 재생 버튼 없음 — IPA만 보고 실제 소리를 확인할 수 없어서, 면접에서 그 단어를 직접 말해야 하는 하늘 입장에서는 아쉬운 지점. (다만 브라우저 자체 TTS나 사전 앱으로 우회는 가능.)

**🗯️ 하늘의 속마음**
"검색이 없어? 나중에 '그 국회의원 기사 뭐였지' 하고 찾으려면 스크랩 걸어놓는 수밖에 없네. 발음 버튼도 없고. 근데 키보드로만 다 되는 건 좀 놀랍다 — 이런 디테일은 신경 썼네."

## 세션 5 — 모바일 + 공유

**한 일**
- 뷰포트를 390×844(모바일)로 바꿔 홈·기사 화면을 확인. 카드 레이아웃이 1열로 깔끔하게 재배치되고, 본문 줄바꿈·여백도 데스크톱과 동일한 품질로 반응형 처리됨.
- 기사 상단 아이콘(뒤로/저장/글자크기/다크모드)을 다시 확인 — **공유(공유하기·링크 복사) 버튼이 데스크톱에도 모바일에도 없음**. HTML 전체에서 "share/공유/clipboard/navigator.share"를 검색했지만 전부 본문 텍스트("shares", "share of the world's oil" 등) 우연의 일치였고 실제 공유 기능은 존재하지 않음.
- 서버 사이드 렌더링 원본(`curl`)으로 메타 태그를 확인 — `<title>BRIEFLY</title>` 하나뿐이고 `og:title`, `og:description`, `og:image`, `twitter:card` 등 **Open Graph 메타 태그가 전혀 없음**. 즉 URL을 수동 복사해서 카카오톡 등에 붙여넣어도 링크 미리보기(제목·설명·썸네일)가 뜨지 않고 밋밋한 URL 텍스트로만 보임.
- 모바일에서 저장(🔖) 버튼은 정상 동작 확인(클릭 시 채워진 아이콘으로 상태 변경, localStorage의 `bookmarks`에 반영).

**😊 만족**
- 모바일 반응형 자체는 흠잡을 데 없음. 폰트 크기, 줄 간격, 터치 타깃 크기 다 무난함.
- 북마크(스크랩) 버튼은 모바일에서도 잘 동작.

**😤 마찰**
- (상) 공유 버튼이 아예 없음 — 친구에게 기사 보내려면 브라우저 주소창에서 URL을 수동으로 복사하는 수밖에 없음. "면접 스터디 단톡방에 이 표현 공유해야지" 하는 흐름이 원천 차단됨.
- (상) Open Graph 메타 태그 부재로, 수동 복사한 링크를 카톡/SNS에 붙여넣어도 미리보기가 안 뜸 — 링크가 휑해 보여서 공유해도 "이게 뭐지" 하고 안 눌러볼 가능성이 큼. 바이럴이 될 수 있는 콘텐츠(예: 재밌는 헤드라인)라도 공유 순간의 매력이 사라짐.

**🗯️ 하늘의 속마음**
"어? 공유 버튼이 없네. 그냥 링크 복사해서 보내야 되나... 근데 이거 카톡에 붙여넣으면 미리보기도 안 뜨겠는데? 그럼 친구가 눌러보지도 않을 듯. 이건 진짜 아쉽다, 서비스 알리기 딱 좋은 콘텐츠인데."

## 종합 판단

**SNS에 자발적으로 공유할 것인가 — 아니다, 지금 상태로는 안 한다.**
근거: (1) 공유 버튼 자체가 없어서 "공유"라는 행동을 시작할 진입점이 없음. (2) 설령 URL을 수동 복사해도 OG 메타 태그가 없어 링크 미리보기가 텅 비어있음 — 하늘처럼 "좋으면 SNS에 공유하는" 성향의 파워유저에게 이 두 가지는 공유 의욕을 꺾는 결정적 장애물. 완주 화면(스트릭)처럼 "캡처해서 자랑하고 싶은" 순간은 있었지만, 그것도 스크린샷을 수동으로 찍어 올리는 것 이상의 지원(공유 카드, 공유 시 자동 문구 등)은 없음.

**"B2가 최고 레벨이면 나한텐 너무 쉬운 거 아냐?" 문제의 실제 체감**
절반만 맞았다. 문장 난이도·어휘 자체는 하늘에게 그렇게 쉽지 않았다 — 시사 용어(aortic dissection, war powers resolution 류)가 섞여 있어 B2도 술술 읽히진 않음. 하지만 **정보량 자체가 원문보다 훨씬 얕다**는 게 진짜 문제였다: 원문에는 있는 직접 인용문, 구체적 수치, 정치적 맥락(상원 의석수 등)이 B2 버전엔 빠져있어서, "레벨이 쉬워서 시시하다"기보다 "내용이 요약되어 정보가 부족해서 결국 원문을 또 봐야 하는" 방식으로 불만이 나타났다. 즉 레벨 상한 자체보다 "B2=쉬운 문장 + 얕은 정보"라는 조합이 파워유저에게는 어중간하게 느껴짐.

**심각도 "상" 마찰 (3건)**
1. 몰아서 읽기 도중 서버 다운 — 완주 흐름 자체가 끊김(로컬 개발 환경 이슈이나 체감 타격 큼).
2. 공유 버튼 전무 — 친구에게 기사를 보내는 진입점이 아예 없음.
3. Open Graph 메타 태그 부재 — 수동 복사한 링크도 미리보기 없이 휑하게 전달됨.

**최우선 개선 3가지**
1. **기사 공유 버튼 + OG 메타 태그(제목·요약·썸네일) 추가** — 지금 가장 크게 비어있는 지점이자, 신규 사용자 유입과 직결되는 부분.
2. **단어장/문장함 내보내기(복사 전체·CSV·노션 연동 등)** — 표현을 모아놓고도 꺼내 쓸 방법이 없어 "수집 → 활용" 흐름이 끊김.
3. **검색 또는 최소한 저장 목록 내 키워드 필터** — "그때 그 기사" 재탐색 수단이 스크랩 말고는 없음.
