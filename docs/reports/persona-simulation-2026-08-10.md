# 페르소나 시뮬레이션 통합 보고서

2026-08-10, 메인 에이전트 종합. 방법: 페르소나 3명 × 5세션 = 15세션을 실제 브라우저(Playwright)로 조작, 스크린샷 79장. 원본: [p1-kimseoyeon.md](persona-raw/p1-kimseoyeon.md) · [p2-parkjunho.md](persona-raw/p2-parkjunho.md) · [p3-leehaneul.md](persona-raw/p3-leehaneul.md)

> 주의: 시뮬레이션은 AI가 페르소나를 연기한 것으로, 실사용자 테스트를 대체하지 않는다. 다만 세 페르소나의 지적이 서로 수렴하는 지점은 신뢰도가 높다.

## 1. 판정 요약

| 페르소나 | 핵심 질문 | 판정 | 한 줄 이유 |
|---|---|---|---|
| 김서연 (29, 마케터, A2, 모바일) | 7일 후에도 쓸까? | **조건부 생존** | 핵심 루프(15분 완주·스트릭)는 습관이 될 만함. 주변 동선에서 걸림 |
| 박준호 (35, 과장, B1, 기기 병행) | 월 5천원 낼까? | **아니오** | 레벨 재작성·출처 검증은 진짜 차별점으로 인정. 그러나 "매일" 약속(콘텐츠 정체)과 기기 동기화가 깨져 있음 |
| 이하늘 (24, 취준생, B2, 데스크톱) | SNS에 공유할까? | **아니오** | 자랑하고 싶은 순간(완주·스트릭)은 있는데 공유 버튼·OG가 아예 없음 |

세 판정 모두 부정적이지만, **이유가 전부 "이미 알고 있고 고칠 수 있는 것"으로 수렴**한다. 제품 방향 자체에 대한 부정은 한 건도 없었다.

## 2. 수렴 마찰 (2명 이상 지적 = 최우선)

1. **콘텐츠 최신성** (P1 혼란 + P2 심각도 상) — 브리핑이 28일째 7/13에 멈춰 "매일"이라는 핵심 약속 위반. → **오늘 배포(파이프라인 매일 실행)가 곧 해법.** 이 발견은 "배포가 왜 최우선인가"의 실증.
2. **사전 커버리지** (P1 중 + P2 상) — 기사당 5개 단어만 뜻이 있음. 모르는 단어일수록 "뜻 준비 중"에 걸림. → API 연결됐으므로 파이프라인 사전 생성 단계(§4.9 계획) 구현이 다음 콘텐츠 우선순위.
3. **로그인/기기 동기화** (P2 상, P1·P3도 전제) — localStorage 한계. → Supabase 연결 직후 1순위.

## 3. 고유 발견

- **P3 — "B2 상한" 문제의 재정의 (핵심 통찰)**: B2가 시시한 게 아니라 **얕다**. 난이도는 적당한데 원문의 구체 수치·인용·맥락이 빠져 결국 원문을 또 읽게 됨. "쉬워서 불만"이 아니라 "요약이라 불만". → 대응: B2 재작성 지침을 "표현은 B2, **정보 밀도는 원문급**"으로 수정 (2소스 확인된 수치·맥락 최대 포함). 난이도 게이트가 아닌 **정보 보존율** 관점 — C1/C2 사용자 대응 전략(레벨 추가 없이)과도 일치.
- **P3 — 공유 버튼·OG 메타태그 전무**: 성장 루프가 0. Batch 2 예정이었으나 우선순위 상향 근거 확보. + 단어장 내보내기(현재 삭제만 가능), 검색.
- **P1 — 에러 화면 정비**: 아카이브에서 흰 Internal Server Error 1회 관측(서버 불안정 시간대와 겹쳐 상시 결함 단정 불가). 상시든 아니든 브랜딩·복귀 경로 있는 에러 바운더리 필요. + 기사 스크롤 위치 미저장.

## 4. 확인된 강점 (지킬 것)

- 15분 완주 루프·진행 표시·스트릭 — "습관이 될 만하다" (P1)
- 레벨 전환 + 출처 검증 — "실제로 확인되는 진짜 차별점" (P2, 신뢰 고지를 직접 검증해봄)
- 완주·스트릭의 자랑 욕구 유발 (P3) — 공유 기능만 붙으면 성장 루프로 전환 가능
