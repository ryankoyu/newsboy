# Top 10 큐레이션·필터링 설계

2026-07-13, 메인 에이전트 작성. 배경: 첫 실제 에디션이 미국 정치에 편중 (World 5개 중 3개가 미 의회 인물 뉴스). 사용자 지적으로 필터링 방식 연구.

## 0. 편중의 원인 (진단)

1. Google News 쿼리 전부 `gl=US` 미국판 → 미국 시각 뉴스 유입
2. 데모 선정이 "보도 매체 수" 순 → 서구 매체 중심 소스에서 미국 정치가 구조적으로 승리
3. 카테고리 균형이 코드 강제가 아니라 의도 수준 (이번엔 Business 소스 부족으로 World가 백필까지 받음)

## 1. 3층 필터링 구조 (제안)

### Layer 1 — 하드 룰 (코드가 강제, AI를 신뢰하지 않음)

- **카테고리 쿼터 고정**: World 3 / Korea 2 / AI·Tech 2 / Business 2 / Culture·Sports 1. 백필은 같은 카테고리 차선 후보 → 없으면 인접 카테고리 (World로 몰아주기 금지).
- **동일 국가 내부 정치 최대 2건** (미 의회 인물 3건 같은 구성 차단).
- **동일 인물/기관 중복 금지**: 같은 인물·기관이 주어인 사건은 1건만.
- **World 3건은 지역 분산 지향**: 가능하면 서로 다른 지역(아메리카/유럽/아시아·중동/기타)에서.
- **톤 밸런스**: 죽음·참사·전쟁 기사 연속 배치 제한 (10개 중 최대 4~5건), 마지막 슬롯은 가볍거나 긍정적인 뉴스 보장 (기존 전략의 Culture 슬롯 취지).
- 2소스 규칙 유지 + **소스 중복 판정 강화**: 같은 매체의 다른 피드는 1개 소스로 계산 (rank8 사건 재발 방지 — URL·매체 기준 dedup).

### Layer 2 — 중요도 점수 (후보 랭킹)

각 클러스터에 합성 점수:

| 신호 | 의미 | 산출 |
|---|---|---|
| 매체 다양성 | 몇 개의 **서로 다른** 매체·국가가 다뤘나 | 소스 dedup 후 count + 국가 다양성 가중 |
| 한국 관련성 | 한국 독자에게 직접 영향 | 한국 매체(연합·KH) 동시 보도 여부, 한국 키워드 |
| 글로벌 영향력 | 세계적 파급 | GDELT 메타데이터(기사 수·보도 국가 수) — 무료, 키 불필요. **점수 신호 전용이며 수집 소스가 아니다**(news-sourcing-strategy.md §1) |
| 학습 적합성 | 영어 학습 소재로 적절한가 | LLM 판정: 서사 명료성, 보편 어휘, 지식 전제 낮음 |
| 신선도 | 오늘 발생/발전했나 | 발행 시각 |
| 감점 | 특정국 내부 정치 디테일, 가십, 선정성 | 룰 + LLM |

### Layer 3 — LLM 편집회의 (API 키 연결 후)

점수 상위 25~30 후보를 LLM에게 주고 "한국 성인 독자의 오늘 10개"를 근거와 함께 선정. **단 결과는 Layer 1 룰로 코드가 재검증** — AI가 쿼터를 어기면 코드가 교정. (AI는 제안, 룰은 강제)

## 2. 소스 다변화 (편중의 뿌리)

- Google News 쿼리 지역 다변화: `gl=US` 단일 → 미국판 + 영국판(`gl=GB`) + 주제별 쿼리 확대 (Asia, Europe, economy, global markets)
- **Business 전용 소스 보강** (현재 Google News 1개뿐이라 2소스 게이트 통과 불가): BBC Business RSS(확인됨) + 추가 후보 검증 필요 (CNBC/MarketWatch/FT 무료 RSS 여부·약관)
- 아시아·유럽 관점 매체 보강 후보 (RSS 제공·약관 확인 필요): DW(독일), France24, Nikkei Asia, Straits Times, SCMP
- ※ 신규 소스는 R1 방식대로 실제 RSS 작동 + 약관 확인 후 화이트리스트에 추가

## 3. 관심사 개인화 (온보딩 관심사와 연결 — 제품 결정 필요)

긴장 관계: "모두가 같은 오늘의 10" = 브랜드 자산 vs 관심사 다른 사용자.

**제안 — 코어+포유 구조**: 공통 "Today's 10"은 유지(브랜드·대화 소재)하고, 관심사 기반 "For You +N" 섹션을 별도로 (예: 축구 선택자에게 스포츠 2건 추가). Top 10 자체를 개인화하면 "오늘 이 10개만 읽으면 된다"는 신뢰 자산이 사라지므로 권장하지 않음.

- V2 관심사 큐레이션과 연결. MVP에서는 Layer 1~2까지만으로도 편중 문제 해결 가능.

## 4. 적용 로드맵

1. **지금 (코드만으로 가능)**: Layer 1 하드 룰 + 소스 dedup 강화 + Google News 지역 다변화 + Business 소스 보강 → selectTop10 재작성
2. **API 키 연결 시**: Layer 2 학습 적합성·Layer 3 편집회의 활성화 — **2026-08-12 현재 구현·배선 완료**(GDELT 글로벌 영향력 신호 포함). 실행 산출물로는 아직 확인되지 않았다. 현재 판정은 `docs/feature-status.md` §1-A와 G7 참조
3. **V2**: 코어+포유 개인화
